# HANDOFF — repository adaptation

Before ending work, update HANDOFF.md with current goal, confirmed changes, verification evidence, unresolved blockers, and the exact next action. At the start of the next session, read HANDOFF.md and the planning files before making changes. Never claim a tool succeeded unless the result was verified. Preserve prior research records. This is a minimal repository adaptation, not the upstream full skill or automatic hooks.
