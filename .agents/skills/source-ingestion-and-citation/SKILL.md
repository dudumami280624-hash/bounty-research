# Source Ingestion and Citation

Convert books, papers, shareholder letters and public data into traceable evidence cards.

For every card record: source title, author, edition, page or section, source URL or file path, retrieval date, exact claim, paraphrase, evidence type, confidence and permitted use.

Separate quotation, paraphrase, inference and adaptation. Never claim a book was read when only its bibliography entry exists. Preserve source hashes and original files where available.
