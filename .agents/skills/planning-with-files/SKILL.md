# Planning with Files — repository adaptation

Before multi-step work, read task_plan.md, findings.md, and progress.md. Update task_plan.md when scope or next steps change. Record verified findings in findings.md, and executed commands, results, failures and blockers in progress.md. Never mark a task completed without evidence. Preserve existing files. This is a minimal repository adaptation, not the upstream full skill or automatic hooks.
