# yt-dlp 视频资料采集

## 目的
使用 yt-dlp 采集公开、允许访问的视频资料，为市场心理学与投资研究建立可追溯文本来源。

## 标准流程
1. 接收公开视频 URL；记录 URL、平台、标题、作者、发布日期和采集日期。
2. 优先下载字幕：人工字幕优先，自动字幕次之；记录语言和字幕类型。
3. 没有字幕时，仅在授权且环境具备语音转写能力时提取音频，不把猜测当成原文。
4. 保存元数据 JSON、字幕/转写文本和 SHA-256 哈希。
5. 将视频拆成主张，区分原话、释义、推断和原创改写。
6. 每条可用主张创建证据卡，记录时间戳、来源 URL、置信度和核验状态。
7. 对投资观点进行独立核验；视频内容不能单独作为历史事实或交易建议的充分证据。

## 仓库输出
- knowledge/video-sources/raw-metadata/：元数据 JSON
- knowledge/video-sources/transcripts/：字幕或转写文本
- knowledge/video-sources/evidence-cards/：核验后的证据卡
- knowledge/video-sources/manifest.json：来源、哈希、状态和重复检查

## 版权与访问边界
只处理用户有权访问、下载或研究的公开资料；不绕过登录、付费墙、DRM 或访问控制；不把整本受版权保护的内容重新发布。仓库保存短摘录、事实摘要和必要的出处，不保存不必要的完整复制品。

## 质量门槛
没有字幕或转写、无法确认来源、或无法定位时间戳时，状态必须标记为 UNVERIFIED，不得进入已验证章节。
