# 股票技术教学知识库 | Trading Education Knowledge Base

> 状态：已建立课程资料索引、研究流程与X文章草稿。教材提取、逐页图表审核及事实核验仍在进行；文件登记或提取状态不等于完成研读。仓库为公开仓库。

## 目标
长期保存课程原文与结构化知识，支持未来按主题查询、引用、编写英文 X Articles。**原文和改写严格分开**；未经核实的观点标记为“待核”。

## 目录（以仓库实际文件为准）
- `source-files/` 已登记的来源文件与相关记录；不得把文件存在视为内容已核验
- `inventory/` 文件总清单、读取状态与哈希
- `taxonomy/` 知识分类标准、课程前置关系
- `concepts/` 已整理的主题知识卡；`source-reviews/` 来源审阅记录
- `integration/` 提取进度、交叉研究与待核事项
- `x-articles/` 课程衔接、已发布版本与英文编辑草稿
- `templates/` 长文及案例模板

## 每份课件的记录字段
- 文件名、原始标题、版本、语言、来源、使用许可
- SHA-256、页数、是否读取全文、是否含图表、图表是否已检查
- 分类、关键概念、课程难度、前置课程、原文引用位置
- 事实核验状态：通过 / 存疑 / 未核验
- 长文状态：未开始 / 中文审核 / 英文审核 / 已发布
- 对应 X 帖子链接（如适用）

## 固定工作流程
1. 接收课件，先确认版权与公开范围。
2. 保存原文件副本并计算 SHA-256；不更改原文。
3. 逐页核对文字、表格、K线图和标注，标记实际读取范围。
4. 去重、分类、建立交叉引用；有冲突不擅自覆盖。
5. 形成中文课程大纲，用户审核后再改编为英文 X Articles。
6. 每篇文章记录来源文件和版本；英文对外发布，中文供审核。
7. 不荐股、不承诺收益；注明技术分析局限。
