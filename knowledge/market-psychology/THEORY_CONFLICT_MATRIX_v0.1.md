# Theory Conflict Matrix v0.1

| Question | Chanlun-inspired structure | Trend following | Value / fundamental | Efficient-market view | Behavioral view |
|---|---|---|---|---|---|
| Unit of analysis | nested price structure | persistent return movement | cash flow and valuation | information and price | belief and decision |
| Main signal | balance, segment, exhaustion | breakout, persistence, volatility | margin of safety | risk-adjusted benchmark | attention, bias, positioning |
| Strength | timing and structure | regime persistence | valuation discipline | benchmark and null hypothesis | explains deviations |
| Failure mode | hindsight and ambiguity | range whipsaw | value traps and timing | ignores frictions and limits | difficult measurement |
| Required test | pre-defined structure rule | out-of-sample trend rule | valuation benchmark | abnormal return test | behavior proxy plus outcome |
| Operational use | hypothesis about state | risk-managed exposure | fundamental constraint | default benchmark | mechanism and diagnostic |

## Decision rule

No framework wins globally. Each chapter must state the question, horizon, data and loss function before selecting a model. Similar charts do not establish theoretical equivalence.
