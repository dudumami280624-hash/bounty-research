# grill-with-docs Audit — Frozen Structure v0.1

## Verdict

NEEDS REVISION — do not mark the ten chapters publication-ready yet.

## Findings

### 1. Evidence-card index is stale

The index still lists CARD-004 through CARD-010 as required next, but those cards now exist. The ledger must be updated before continuity can be trusted.

### 2. Case sources are not the same as extracted data

The data register correctly distinguishes SOURCE LOCATED or PRIMARY LINKS ATTACHED from completed extraction. No chapter may cite a case as verified until the relevant point-in-time data, dates, units and calculations are attached.

### 3. Mapping is provisional

The chapter mapping is useful, but its own freeze rule says mapping is not final until data, source, counterexample and invalidation are recorded. Therefore the sequence can be frozen while the case mapping remains provisional.

### 4. Glossary lock needs a revision protocol

Definitions are labelled LOCKED v0.1 but also subject to evidence-based revision. This is acceptable only if a changed definition creates a new version and preserves the prior definition.

### 5. Publication gate is correctly blocked

The chapter plan requires an original diagram, bilingual X thread and grill verdict. Those artifacts do not yet exist for all ten chapters.

## Required repairs

1. Update the evidence-card index.
2. Extract and hash the first case dataset, starting with 2008 or 2020.
3. Attach one counterexample and invalidation condition to every mapped case.
4. Create glossary v0.2 only when evidence changes a definition.
5. Draft Chapter 1 only after its evidence card, US case card, diagram plan and X thread pass review.
