# Hypothesis Register v0.1

| Chapter | Testable hypothesis | Variables | Failure condition |
|---|---|---|---|
| 1 | Narrative change adds information beyond price and volume | narrative proxy, returns, volume, volatility | no out-of-sample incremental value |
| 2 | Balance-zone breaks differ from random breaks | zone width, breakout, forward return | no improvement after costs |
| 3 | Persistent trends contain exploitable continuation | moving averages, momentum, forward return | performance disappears out of sample |
| 4 | Predefined momentum exhaustion changes reversal odds | momentum, divergence, reversal | no conditional difference |
| 5 | Predefined decision zones improve risk-adjusted outcomes | entry, stop, target, drawdown | worse than benchmark |
| 6 | Macro regimes alter local asset risk | rates, CPI, credit, returns | no incremental explanatory value |
| 7 | Behavioral bias predicts holding/selling decisions | disposition proxy, realized/unrealized return | proxy has no predictive value |
| 8 | Leverage amplifies tail moves and liquidation | leverage, spreads, volatility, drawdown | no relation after controls |
| 9 | Precommitted invalidation improves survival | rule, exit, drawdown, recovery | benefit vanishes after costs |
| 10 | Calibrated uncertainty improves decisions | probability, confidence, outcome | calibration does not improve decisions |

Each hypothesis requires a benchmark, pre-specified sample split, counterexample and invalidation record.
