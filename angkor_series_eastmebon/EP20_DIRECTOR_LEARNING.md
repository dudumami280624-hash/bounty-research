# EP20 东梅奔 East Mebon · 导演学习卡（v1 自检）

## 本集事实（已核实）

- 哇塞核心 A「八尊石象」（用户点选）；用户另定：历史反差「湖水消失，寺庙仍在」；0 秒「直接出现东南角石象，不做铺垫」。
- 953 年 1 月 28 日奉献，Rajendravarman II 建，印度教供奉湿婆、纪念国王父母；原名 Shrirajendreshvara；建筑师 Kavindrarimathana。
- 旧东大水库中央人工岛寺，水库今已干涸；三层金字塔＋两重围墙；顶层五座砖塔五点式（中央湿婆、东北毗湿奴、东南梵天、西北母、西南父）。
- **石象共 8 尊、两米高**，在一、二层转角（最完整西南、西北；最上镜东南；最独立东北）；另有石狮；四面各一座石质登船台。
- 材料：砂岩、砖、红土、灰泥（砖塔灰泥已脱落、留锚孔）。

## v1 自检发现的问题（两处，v2 已修）

### 问题 1：S01 的 0 秒不是一眼能认出的象（v2 已修）
- v1 的 0 秒帧：石象的身体侧面（曲面石身＋雕刻鞍具），象头、象鼻、眼睛都不在框里。观众 0 秒看到的是"雕刻石头"，不是"象"。
- 违背：用户定的「0 秒直接出现东南角石象，不做铺垫」＋0 秒标准「一眼认出」。横移从身体开始、几秒后才移到头，本身就是铺垫。
- v2 修正：S01 重做，提示词写死「象头、象鼻、眼睛从第 0 秒就在框里，象头占满竖屏」；0 秒、5 秒抽帧确认象头在框、一眼认出。

### 问题 2：S06 结尾 59 秒推得太紧，只剩一只眼（v2 已修）
- v1 的 59 秒帧：推到只剩眼睛＋部分象鼻，脸被裁掉。50 秒、55 秒象脸完整，只有 59 秒过紧。
- 与 EP19 v1 的 S03 是同一个毛病：10 秒推近，再慢也会推过头。
- v2 修正：S06 重做，提示词写死「象脸全程都在框里、59 秒仍是整张脸，不推到只剩眼睛」；50、55、59 秒抽帧确认脸全程完整。

### 其他段没问题（v1、v2 相同）
- S02（15 秒）：五塔＋多尊象＋旱地，五塔齐全，砖塔红褐、象灰褐，地面干、无水。
- S03（20、25 秒）：象头全程完整，双耳、象鼻、眼睛都在框里，雕刻细节清晰（EP19 教训已落实）。
- S04（30、35 秒）：砖塔仰拍，砖面灰泥锚孔可见。
- S05（40、45 秒）：远景干裂旱地＋庙，五塔齐全，无水，「湖没了、庙还在」立住了。

## 复盘四项（v1 阶段）

### 错哪里了

- S06 推近的终点没管住：10 秒推近即使"极缓慢"，59 秒还是推到只剩眼睛。推近的终点必须写死，不然一定推过头。

### 下次如何去做
