# Price tier claim checks

## Verify each expensive tier before you generate

- List every item and its two price tiers before you generate any image or video.

- Search for a real purchasable example at each expensive tier and record its name and price range.

- Open the product page or an established retailer listing and read the price there, and do not accept a search snippet as proof.

- Treat a category that contains one very expensive item as unproven for a different material, and check the exact material you claim.

- Check the cheap tier too when it names a specific model or material, and accept a generic cheap item only when the category is sold at that price.

- Do not generate the set, add the price labels, or tell the user it is ready to post until every tier passes.

## Replace a failed tier instead of inventing it

- Drop a tier when no real example reaches its price, and do not stretch a lower priced example to fit the label.

- Offer a verified replacement from the same kind of item when you can name a real example at the tier, and ask the user to choose it before you generate.

- Keep the tiers that passed and rebuild only the failed pairs, and do not rebuild the whole set to fix one pair.

- Qualify a rare edition claim in the plan when only a signed or first edition reaches the tier, and do not present the rare case as an ordinary product.

## Retract a delivered claim before the user posts

- Check the set again when new evidence appears after delivery, and retract the failed tiers at once when the check fails.

- Name each failed tier and the real price range you found, and name the tiers that still pass so the user can keep them.

- Offer verified replacements with their names and price ranges, and wait for the user to choose before you rebuild.

- Do not tell the user a set is ready to post on the day when any tier is still unverified.

## Websites

- [Google Shopping](https://shopping.google.com/) for finding sellers of the same item, and verify each price on the seller product page.

- Search the brand official store and established retailers for the exact model, and read the price on the dedicated product page.

## Alternatives for better results

- Ask the user to pick a different item when no real example reaches the tier.

- Use a lower tier that real examples reach when the user accepts a smaller gap.

- Offer a different comparison format when the user still wants the item and no real example reaches the tier.
