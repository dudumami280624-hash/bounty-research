# Skill Learning Loop

Use this skill when learning a new method, so one success never becomes a general rule and text research never becomes audience proof.

## Record a method in three columns

- Record the method itself, its evidence grade and its limit. Use official documentation, public text, author self report or unverified as the grade, and write what is not proven in the same entry.

- Test each new method on one validation point in one episode only. Never roll it out across a whole season before the test.

- Report the test as pass or fail with the change it caused. Never report a viral guarantee, a follower guarantee or a retention guarantee.

- Add only one new standard per round. Never let a new standard overturn a user approved main line or ruling, and never overwrite an old version.

## Close every report with what was not done

- List every unfinished check in its own section. Include unwatched full videos, missing trademark searches, missing reverse image checks and missing voice and crop tests.

- Revise the direction of this skill only after user approval. Never expand its permissions on your own, and never save a password, a token or account information inside a skill.

## Available connectors

- Use `muse.connector_search` to find other connectors and `muse.skill_search` to find related skills.

- If nothing here fits, look on the web for a maintained API or MCP server and set it up with [Custom Connectors and MCPs](/opt/muse/skills/custom-connector-setup/SKILL.md), or build a custom connector.
