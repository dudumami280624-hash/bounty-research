# CLIPCAT COMEDY ROOM V1.0
美式成人黑色喜剧编剧与终审工作流 | 项目：DICED AFTER DARK

## 状态
- 系统：已建立为可重复使用的文档流程；**不等于自动化 Skill、真实观众测试或模型独立复审已运行**。
- V4 剧本：**NOT LOCKED / FAIL**（前次文字自审6.8/10，仅主观评估）。
- 五张角色母图及已批准资产：**LOCKED**。不得重绘、替换、擅自修改。此目录不存放或覆盖母图。
- 本系统不能自称“独立评审团”；同一模型自审必须标注 SELF-REVIEW。
- 工作规则：一次性列出所有阻断项，集中修订，保留旧版；不得每轮新增无关标准。

## 入口与文件
1. [WRITERS_ROOM_RULES.md](WRITERS_ROOM_RULES.md) — 先研究、再编剧、再审查的门槛和评分标准。
2. [REVIEW_TEMPLATE.md](REVIEW_TEMPLATE.md) — 每次审核必须复制并填写，逐镜有证据。
3. [EVIDENCE_REGISTER.md](EVIDENCE_REGISTER.md) — 外部案例与观众数据登记；**初始为空，不得虚构**。
4. [V4_BASELINE_AUDIT.md](V4_BASELINE_AUDIT.md) — 现有V4问题基线与修订边界。

## 执行命令（复制给任何协作模型）
“按 film/diced-after-dark/comedy-room/README.md 和 WRITERS_ROOM_RULES.md 执行。先读取当前剧本及 LOCKED 资产索引；不得猜测缺失文件。先填写 REVIEW_TEMPLATE.md 全40镜审核；输出证据、失败点、优先级与一次性修订建议。未满足门槛不得宣称终审通过，不得修改 LOCKED 资产。区分 SELF-REVIEW、EXTERNAL-REVIEW、PRODUCTION-TEST 与 AUDIENCE-TEST。”

## 发布闸门
研究证据 → 故事/人物喜剧机制 → 40镜完整脚本 → 文本质量审核 → 第二模型/独立人员复审（如可用） → 6秒配音/画面/裁切实测 → 用户批准 LOCKED。
没有第二模型时可继续修改，但**不能标记独立复审已通过**；没有实际成片不能标记制作验证通过。

## 版本原则
新稿另存V5/V6，不覆盖原版、V3或V4；每次记录变更、理由、受影响镜头和回归测试。用户明确批准后才能标记 SCRIPT LOCKED。
