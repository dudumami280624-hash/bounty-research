# MASTER_DIRECTOR_SYSTEM.md

最新通用制作规范（总章程 v3.0 的执行摘要；全文见 beyond_angkor_ai_master_charter_v3.md）。

## 最高原则

- 每集必须有自己的视觉身份，不复制上一集。
- 六段是叙事骨架，机位是工具，真实遗址是依据，观众体验是目标。
- 继承已验证经验，同时尝试合理的新方法；每次失败必须带来新的解决方案。
- 已封存作品不因新规则而追溯返工；不凭未经证实的判断强制重拍。

## 统一技术标准

- 9:16 竖屏、60 秒、S01–S06 每段约 10 秒。
- 写实电影感、真实建筑比例；明亮自然冷光为主，局部克制暖金侧光。
- 旁白原创美式英语，中文仅供审核；无歌词配乐；不加硬字幕。
- 旁白时间轴：S01 02–09s、S02 12–19s、S03 22–29s、S04 32–39s、S05 42–49s、S06 52–59s、59–60s 留白。
- 调色：`colorbalance=bs=-0.12:bm=-0.06:bh=-0.03,eq=brightness=0.08:saturation=0.95`，去音轨 `-an`，CRF 21；成片目标 60.00 秒、720×1280、24fps、仅视频流、＜80MB。

## 六段叙事

- S01 视觉爆点：一个巨物占满画面，0 秒主体在、1 秒在动、2 秒提悬念。
- S02 揭示空间：主体所在的位置、环境、建筑关系或真实规模；不强制后拉。
- S03 历史细节：最有价值的雕刻、材质、树根、苔藓、裂纹；须为新视觉信息。
- S04 视角变化：改变高度、方向、距离或运动，揭示新空间关系。
- S05 尺度与情绪：建筑大小、空间深度、历史氛围；不强制生成人物。
- S06 记忆收束：最后揭示；不强制全景结尾。

## 开工前必做

1. 读 46 集资料库对应集数＋APSARA/官方专页；至少 2 张有来源的不同角度真图并逐张验看。
2. 读最近三集镜头记录（EPISODE_SHOT_HISTORY.md），做跨集轮换检查（S01 主体、景别、角度、运动；六段景别变化；S06 收尾）。
3. 写调研、照片对照、章程三件文件；报哇塞核心 A/B/C 等用户点选（或用户授权导演定）。
4. 提示词首版即写死：遗址身份、主体、建筑结构、保存状态、景别机位、镜头运动、光线、质感、连续性、禁止内容；数字写位置（左、中、右）；雕刻分浅浮雕/深浮雕/独立雕像/门楣；残损写进首版。

## 失败处理

- 第一次失败：定位具体问题，只改相关提示词。
- 第二次同类失败：停掉原方案，换机位/景别/更简单运动/更稳定构图/真实构件特写/已有素材剪辑。
- 禁止：同一失败反复重试；为修一个问题推翻全部镜头；因轻微艺术差异要求整段重做。

## 每集闭环

研究 → 读历史经验 → 找独特视觉主体 → 设计六段 → 组合机位 → 一次性核对建筑与历史 → 写完整提示词 → 生成 → 最小修改 → 剪辑 → 基于实际成片复盘 → 记录成功与失败 → 更新摄影库与导演学习库 → 下一集继承并优化。

每集结束后生成 EPXX_DIRECTOR_LEARNING.md（3–5 条最重要经验，不凑数），并更新本知识库五文件。
