# 通用红线 · 每次调用前先过一遍

- 来不及先存仓库：时间不够、内容多、怕忘的时候，先把学到的、查到的、定下来的东西整理进 `workspace/learning_warehouse/` 再往下做，不要先凭感觉往下说，之后再从仓库里调出来用。
- 学了就写进仓库：每学到一个有用的方法、每查到一个有用的账号、每定下一个标准，都要先过滤、再转化、再写进仓库对应的文件里，才算学完；只留在聊天里不算学会。

- 开工前先对照片和历史：所有制作开工前，必须先对照真实场景图片和柬埔寨历史，确认形制、雕像、宗教元素后再生成；只看文字描述不算对过，照片级形制对照没做完不许开工。
- 宗教元素红线：高棉印度教／佛教遗迹内，不许出现十字架、受难像等外来宗教形象；放进去就是宗教文化冒犯，会招致观众和相关群体的维权投诉，毁系列口碑。审片时人物、雕像、宗教符号逐项对照片，照片里没有的一律不许出现。
- 第六集起零重大事故：认错形制、禁入宗教元素、事实误导、命名代证据皆为重大事故，不许发生；剪辑问题（节奏、开头吸引力、色调统一）须在成片前解决，不留到事后返工。
- 美化与虚构界限：可以优化漂亮点，不能无中生有；把石块轮廓当巨型实物压轴呈现即属虚构误导，必须从成片拿掉，不能只改结论。
- 交付规矩（用户二次加工）：只给干净画面版，无原配音、无字幕；硬字幕裁切字幕带并注明比例变化；不再还带原声或带字幕版。
- 卖号排除：卖账号、卖 Gmail、卖邀请码助力的帖子和链接，一律不收、不贴、不推广；但同一账号里讲方法的部分，可以过滤后只收方法总结。
- 不抄：不抄角色、名字、剧情、台词、视觉资产、原文、提示词原文。
- 不编数：播放、点赞、粉丝、时间以实际查到的为准，查不到就说查不到，不推算、不编造。
- AI 标签：每次发视频前用户自查，FB、油管、TK 三个平台都带 AI 标签；吴哥视频内不加中文、不由助手配旁白，安静版用户自加音乐。
- 风险前置：发片、定名、定格式、定剧本前先过风险项，有风险直说并给改法。
- 学有所成：收进来的必须转化成自己的方法、提示词、分镜、检查清单，才算学会。
- 身份不变：学了谁，助手还是用户的搭档，不变成别人。
- 分类好不乱：methods/ 只放方法、accounts/ 只放账号、memory_snapshots/ 只按日期放记忆、rules_and_index/ 只放规则；一个文件只讲一类，新东西先定文件夹再写，写完更新 index.md。
- 美剧漫剧多平台，不只学红果（2026-11-01 用户定）：美式短剧/漫剧的学习来源以 TikTok、YouTube Shorts、Facebook Reels、Instagram Reels、ReelShort、DramaBox 等美式平台为主，红果只是中国短剧的一种参考，不是唯一标准，更不是美式水果剧的模板；中国短剧的付费墙、60-100 集、分账套路不直接套到美式 60-90 秒 TikTok 剧上。
- 面向美国观众，不是中国观众（2026-11-01 用户定，硬规则）：可以学习中国资料，但中国的方法不可以直接应用到美国。学 = 只学机制（为什么有效、节奏、结构、情绪链），用 = 必须按美国观众重做：英文、美式幽默、美式文化梗、美式平台规则、美式观众期待，2 秒内美国观众能 get 到才算过；凡是依赖中国文化、中国梗、中国社会热点、中国付费墙、中国审查套路的方法，一律不直接应用，改不成就砍掉，不硬套。
- 所有翻译按美式风格翻（2026-11-01 用户定，硬规则）：不是中文含义硬翻成美式英文。翻意图、翻笑点、翻情绪，不翻字面：用美式句式、美式缩略、美式习语（有对等习语才用）、美式对话节奏；不保留中文句式套英文词，不逐字翻中文成语，不把中文口号硬翻成英文口号；没有美式对等说法就重写一句意图和动作相同的新美式台词，或者砍掉。事实要对得上（道具、持有人、数字、地点、动作相同），措辞必须是美式的，不是直译的。
- 美式剧本翻中文，是英语意思的中文（2026-11-01 用户再定，硬规则）：美式剧本翻成中文给你看的时候，不是说中文意思的英语，而是英语意思的中文。中文版要忠实表达英文原句的意思、笑点、讽刺和语气，保留它在美国为什么好笑，必要时用括号简单解释美国梗；绝不把英文台词改写成中文成语、中文笑话、中文意思。英文是原件，中文只是给你看懂的 faithful 说明，不进视频、不改原件。
- 固定创作流程（2026-11-01 用户最终决定，硬规则）：①中文定剧情（人物、冲突、反转、不可逆后果、追更钩子，只定意图，不写视频台词）；②英文原创台词（美式口语、美式笑点，不是中文台词的翻译）；③中文对照审核（英语意思的中文，只给你审核原意和情绪是否对，错了改英文，中文对照不进视频）；④英文表演定稿（重音、停顿、反应、6 秒适配，读出来计时）。分工：中文负责确定想讲什么，英文负责让美国观众真正听懂、觉得好笑，中文译文负责让你审核。
- 英文台词好 ≠ 英文表演好（2026-11-01 用户特别强调）：美式黑色幽默往往靠人物说出荒唐话时的严肃表情、停顿和反应，不是靠大喊大叫。默认是冷面（deadpan）+ 严肃脸 + 停顿 + 反应；大喊只作有标记的爆发段，先静止 1 秒、有可见触发点才用；靠喊才立得住的笑点要返修。
- 创作是创作，审核是审核，不要混淆（2026-11-01 用户定，硬规则）：创作回合只做创作（写剧本/分镜/生成，待用户确认后才生成）；审核回合只做审核（列问题、按 proposed / confirmed / false alarm 分级、按镜号给修复清单），审核回合不擅自改片、不擅自生成新版；用户点头说改哪几项，才进下一个创作/修改回合。创作通过 ≠ 审核通过，审核通过 ≠ 自动封存，封存只在用户看完最终版说“可以”之后。
- 项目不混聊（2026-11-01 用户问吴哥去向时的定法）：水果剧审核发在本旁聊（分析古文明短片并策划内容），吴哥不发在这里，吴哥发回它原来的地方（主聊天 / 研究吴哥窟视频），因为两套规则完全不同，混在一起会把美式台词、笑点规则错套到吴哥安静版上。
- Flow 画面一致性根本缺陷（2026-11-01 用户定稿融入重写流程）：旧教程只把 Flow 当拼贴工具，无固定母图、无参考复用、无镜头交接清单；每镜单独生成且用上一镜成片当参考，漂移层层叠加；只有“不一致就重开”，无失败上限、无错误记录、无终止规则。我方反向规则已写入重写流程：LOCKED 母图不动、全片同一套参考、不用上一镜成片、一镜一动作、逐帧质检、同一问题失败两次停。
- 母图由用户提供，流程不锁角色（2026-11-01 用户纠正）：MD 是工具，不是角色锁；用户每集 / 每项目提供母图并确认后才标 LOCKED，流程跟着用户提供的母图走；换一套母图就换一套角色卡，流程本身不用重写；DICED 五人只是其中一套例子，不是流程固定班底。
- 项目与母图绑定（2026-11-01 用户定，最高优先级，v1.4）：硬规则永久有效；每次制作先识别项目 ID、系列 ID、集数、已批准资产版本；未确认母图不用；新项目新账本，原项目换图需批准并开新版本、不覆盖旧图；同一系列续集默认继承，独立新故事只继承明确指定资产；每镜只调实际需要的已批准参考，版本一致；模式不支持就停，不悄悄减参考；无法确认项目、母图、版本时停，不凭记忆猜。
- 吴哥审核标准（2026-11-01 用户定，硬规则）：优先级：历史真实性第一、电影质感第二、镜头连续性第三；不为漂亮牺牲真实，不为修改而推倒重做；每次审核必须明确指出问题镜头、原因和最小修复方案。
- 吴哥每集三目标（2026-11-01 用户定，硬规则）：①前 2 秒抓住观众——这里有什么不同寻常的东西？②中间身临其境——仿佛自己正在探索吴哥；③最后几秒留下向往——让人觉得屏幕里的景色还不够，值得亲眼去看。此规则与 2 秒规则、链式钩子并行：开头的问题须具体（不同寻常之物），结尾既勾下一集、也要勾起亲眼去看的向往。系列终极目标（2026-11-01 用户定）：不是让观众说“吴哥真漂亮”，而是让他们说“下次去柬埔寨，我一定要亲自走进这里”；验证指标为完播率、收藏、分享、观众是否询问地点和路线，不以赞数和播放量本身衡量。
- 吴哥从第 8 集起三个小调整（2026-11-01 用户定，硬规则）：①开头更有悬念——不先介绍景点，直接用最神秘的画面＋问题开场（第 8 集：石像＋“Why is this statue called the Leper King?”）；②每集一个独特发现——不做景点罗列，整集围绕一个发现展开（第 8 集：隐藏的第二道雕刻墙）；③结尾追更理由——不用生硬“关注我”，用一句自然英文收束（第 8 集：“Angkor still has more secrets to reveal.”），该句为解说词、非屏上文字。
- 防忽悠过滤（2026-11-01 用户定）：傻傻忽悠人的资料一律不收，看到以下信号就先排除，不学、不转、不买：承诺保证播放、保证涨粉、保证赚钱；所谓内部算法、秘密流量密码；截图无日期、无账号、无链接可核对；方法说不清、只卖课、只引流到私域付费；账号不存在、长期不更新、粉丝和互动严重不匹配；把个别爆款说成普遍规律；要求先付费、买号、买流量才教方法。核对方法：账号能不能公开查到、最近有没有更新、互动是不是真实、方法能不能在自己一集上复现、失败案例有没有讲，缺一项就先放下，不先信。
