# 吴哥 2 秒抓人法（用户 2026-11-10 亲授）

## 核心
讲遗迹，2 秒抓人的办法不是喊、不是快剪，是 0 秒先给一个具体、反常、占满画面的东西，2 秒只问一个问题。

不是把遗迹讲快，是先给最反常的一块，再问一个最反常的问题。全景、历史、细节全留到 2 秒以后再讲。

## 三招

### 1. 0 秒给巨物，不要给全景
不要一上来就是整座庙、整片湖，那太远了，人看不懂就划走。
要给最近、最有辨识度的一块：
- EP07：石象脸占满画面
- EP18：水里的白马石像占满画面
- EP19：树根里露出来的人面占满画面
- EP21：红砖塔角、仙女浮雕占满画面

### 2. 1 秒镜头已经在动
0 秒巨物一出来，镜头马上推近、上摇、横移，让人感觉这东西是活的，不是照片。静止 2 秒，人就走了。

### 3. 2 秒只问一个问题，不给答案
不要讲历史，不要说"这座庙建于某某年"，2 秒没人听这个。
只问一句过去现在对照：
- "一座庙建在水中央，没有路，怎么进去？"（EP18 涅槃宫）
- "一棵树压住一座门，树死了，门为什么没倒？"（EP19 达松寺）
- "为什么是红的，别的庙都是灰的？"（EP21 比粒寺）
- "五口池子，一座小岛，这里的水真的能治病吗？"（EP18 涅槃宫）

问完就停，答案留在后面，人想听答案就留下来了。

**纠正（2026-11-10）：** 用户初授时举过"它到底是庙，还是火葬场？"为例，但用户随后纠正"怎么烧人了"——比粒寺是国寺、供奉湿婆，不是火葬场，不烧人；"翻身"只是名字传说。火葬场一句不得进解说，不得把"烧人"当钩子。

## 执行要点
- 0 秒巨物必须是特写（最近、最有辨识度的一块），不是全景、不是远景。
- 1 秒镜头必须已经在动（推近／上摇／横移），不能静止。
- 2 秒问题必须是过去现在对照（反常对照），只问一个，不给答案，不讲历史年份。
- 解说稿开头应是这个问题（或与之对应的钩子），不是"这座庙建于某某年"式的陈述。
- 每集开工前先定：0 秒巨物是哪一块特写？2 秒问题是哪一句对照？

## 与既有规则的关系
- 与 2 秒留存规则（0 秒哇塞在画面、1 秒镜头在动、2 秒问题未给答案）一致，是该规则的具体化、可执行版。
- 与 0 秒开场硬标准 v1.1（一主体、占满画面、纹理＋光线）一致，补充了"给特写不给全景"和"2 秒只问一个对照问题"。
- 解说时间轴 S01 02–09s：2 秒问题即解说开头，答案在后续段落逐步揭示（呼应叙事新标准"开头悬念必须有后续回应"）。
