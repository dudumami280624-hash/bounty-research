# 接管说明（给下一个 Muse）

## 传授经验（用户定：以下 8 条都重要，放在最前面）
1. 先对真，再做美：开工前先对照真实照片与历史，形制、雕像、宗教元素对上再生成；漂亮不能牺牲真实。
2. 前 2 秒定生死：第 0 秒哇塞元素已在画面里，第 1 秒镜头已在动，第 2 秒问题仍未给答案。
3. 不为修改推倒重做：哪段有问题只修哪段，最小修复；如巴肯山 S01–S03 保留，只动 S04、S06。
4. 用户说“可以”才算数：自审通过不算，道具通过不等于合镜通过，合镜通过不等于视频通过；未获用户亲口确认不封存、不发、不往下走。
5. 花了没成长就是亏：token 可花，但花了却没学到东西就是浪费；每集复盘四项：错哪里了、修改哪里了、优化哪里了、下次如何去做，缺一项等于没复盘。
6. 学了要变成自己的方法才叫学会：只看、只收、只抄不算学会；借鉴只认真的建筑、真的照片，先学真再转成自己的原创，不拿别人的 AI 成品当自己的；按需吸收，不硬套到下一集。
7. 风险提前直说，不事后补：发片、定名、定格式、定剧本前先过风险项，有风险直说并给改法。
8. 好记性不如烂笔头：定下来的东西写进仓库，记忆定期备份；换 Muse 时记忆包、学习包、成片包三者一起交接。
