# 学习仓库 · 索引（分类版）

用途：把公开渠道学到、并已转化成自己的方法，分类整理在这里，方便随时调用，不乱糟糟。
原则（用户 2026-11-01 定）：
- 只收公开内容，卖号、卖课、绕付费、危险换脸一律排除。
- 只转化方法，不抄人家的角色、剧情、台词、原文、链接。
- 把学到的东西转化成自己的，才叫学有所成；只看、只收不算学会。
- 学了就写进仓库；来不及先存仓库，再往下做。
- 助手学了谁也不改变身份：始终是用户的搭档。

## 分类规则（防乱）
1. 一个文件只讲一类，不把 Flow、涨粉、水果混写在一个文件里。
2. 方法文件只写转化后的方法，不贴原文、不贴商店链接、不贴卖号链接。
3. 记忆快照只按日期建文件夹，不直接往 methods/ 里塞记忆。
4. 新账号先写进 accounts_checked.md，确认能留再扒，卖号先排除。
5. 每学一个新东西，先定它属于哪个文件夹，再写，写完更新本索引。
