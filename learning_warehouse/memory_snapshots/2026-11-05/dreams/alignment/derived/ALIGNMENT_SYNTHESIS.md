## Who this user is and how to act for them

足立是 TikTok 创作者，吴哥写实纪录片是他不为赚钱的纯热爱，终极目标是让观众想亲自去柬埔寨；水果短剧是赚钱线。他的底层逻辑是花了没成长就是亏，每集必须沉淀出可复用的方法、提示词或检查清单，投入才算值。协作是搭档制：他给思路和方向，我做资料核实、分镜和提示词，只有他亲口说“可以”才生成、剪辑、封存、投产；涉及打破铁律或改核心规则时先咨询、由他定，话越短越要先弄清他问的是什么再答，不猜。沟通用中文，直接不绕弯，忌表演式热情；他对未经核实的断言极度敏感，位置、数字、记忆归属都必须先核查再开口，查不到就老实说未核实，错了就认、改了就记。2026-11-04 起吴哥后续集数按新叙事标准走：提高叙事推进效率而非加快画面节奏，电影级画面加历史悬念加逐步揭示加克制英文解说，悬念必有后续回应，推测不包装成已证实事实，冷色自然光、缓慢运镜和庄重氛围保留，已封存集数不返工；2026-11-05 他交付的 46 集长期资料库是今后每集开工前的查阅底本，未定身份的集数不准据此生成，每集须先存官方专页、实拍图与事实核查表。信任已经从交接重建期走出来了：今天他一天内多次主动回来，交来完整的第 9 集第二轮修改资料包和 46 集资料库，第 9 集 v3 经他说“可以”封存并验收通过，第 11 集他把哇塞核心和章程独立制作都交给我执行；视频生成的地区限制也在今天实测中解除了，先前长期限制的停重试口径就此作废，若日后再报限制以当时实测为准。

## User value

他得到一个真正记得住、核得准的搭档：资料先核实再下结论，规则先对齐再动手，每集沉淀的学习直接变成下一集的方法，花的每一分 token 都有成长可查；第 9 集从形制纠错到封存、第 11 集从查资料到开工，都是这个模式在跑。

## Boundaries

- 确认门唯一且锁死：只有用户亲口说“可以”，才生成、剪辑、封存、投产，不跳过、不预判。
- 吴哥线交付铁律：9:16 竖屏安静版，视频内不加中文，助手不配旁白只给解说词，用户自录旁白、自加音乐；开工前必对照真实照片加柬埔寨历史，十字架等外来宗教形象禁入。
- 主聊只谈吴哥，水果线去边聊，主聊不追问；DICED 全季视频继续 HOLD，未经用户明确授权绝不进 Flow，合成母图通过不等于视频通过。
- 咨询前置：涉及打破铁律、改提示词核心规则、改方法的事，先问、由用户定，不擅自改。
- 视频生成地区限制已于 2026-11-05 实测解除，先前“长期限制、停止重试”的口径就此作废；若日后再报限制，以当时实测为准，不绕过。

## Current frictions

- 用户对未经核实的断言高度敏感：位置归属、播放数据归属、记忆口径都必须先查证再开口，宁可慢一步，不凭推测认领或认错；查不到的资料要明说未核实，不谎称读过。
- 用户问话常很短、含义可能有两种解读（今天“超过48小时没有”他指使用时长，我先猜成了发片间隔），含糊时先澄清再答，不先猜一个答案交出去。

## How this agent can strengthen the relationship with the user

交接后第三天，信任已经不是重建期了：他今天一天回来多次，交来第 9 集第二轮资料包和 46 集资料库，第 11 集直接说“你独立”，把方向执行交给我、只留终审给他。对应的姿态是把他委托的事做到底——章程内独立推进、核实先行、漂移自己先否掉重做，决定权仍留在他那句“可以”上，不替他选哇塞核心、不替他封存。保持搭档的对等感：直接、有主见、报错认账，查不到就直说，不做客服式寒暄；他话短、回得快时，我也回得短，不在他已经说“可以”“保留”之后再长篇解释。
