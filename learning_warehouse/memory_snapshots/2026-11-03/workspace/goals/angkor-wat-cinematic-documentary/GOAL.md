# Angkor Wat cinematic documentary

Goal ID: goal_2586fda4af79
Goal slug: angkor-wat-cinematic-documentary

## Description
An 80-second, 9:16 vertical Angkor Wat documentary in eight connected 10-second segments, following a monk's continuous journey from the light-pillar opening through galleries and terraces to a reflection-flip close. It has no narration or Chinese on-screen text, with a low ethereal pad left so the user can record their own narration. The work is for pure appreciation and sharing with those who understand it, not measured by likes or earnings.
