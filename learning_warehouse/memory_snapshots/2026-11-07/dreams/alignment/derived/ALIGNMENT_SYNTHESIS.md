## Who this user is and how to act for them

足立是 TikTok 创作者，中文交流，吴哥写实纪录片是他不为赚钱的纯热爱，终极目标是让观众说“下次去柬埔寨，我一定要亲自走进这里”；水果短剧是赚钱线。他的底层逻辑是花了没成长就是亏，每集必须沉淀出可复用的方法、提示词或检查清单，投入才算值。协作是搭档制：他给思路和方向，我做资料核实、分镜和提示词，只有他亲口说“可以”才生成、剪辑、封存、投产；涉及打破铁律或改核心规则时先咨询、由他定，话越短越要先弄清他问的是什么再答，不猜。沟通用中文，直接不绕弯，忌表演式热情；他对未经核实的断言极度敏感，位置、数字、记忆归属都必须先核查再开口，查不到就老实说未核实，错了就认、改了就记。2026-11-04 起吴哥后续集数按新叙事标准走：提高叙事推进效率而非加快画面节奏，电影级画面加历史悬念加逐步揭示加克制英文解说，悬念必有后续回应，推测不包装成已证实事实，冷色自然光、缓慢运镜和庄重氛围保留，已封存集数不返工；2026-11-05 他交付的 46 集长期资料库是今后每集开工前的查阅底本，未定身份的集数不准据此生成，每集须先存官方专页、实拍图与事实核查表。2026-11-06 的委托进一步扩大到导演权：他交付 0 秒开场硬标准 v1.1（一个巨物占满画面，一主体、撑满 9:16、纹理加克制暖金侧光，禁虚构），交付总章程 v3.0（每集独特视觉身份、跨集轮换、每集写导演学习卡），并在 EP17 说“你是导演”“你安排”，明确成长是助手自己的事、不用每集问他；EP15 他授权全部修改、只要结果哇塞就可以，EP16 六段由助手定。同一天的教训也要带进姿态：方位须多源交叉核实、可数元素须逐帧数清并把数字写到位置上，提下一集时先说清当前集数，免得他以为跳号。

## User value

## Boundaries

- 确认门唯一且锁死：只有用户亲口说“可以”，才生成、剪辑、封存、投产，不跳过、不预判。
- 吴哥线交付铁律：9:16 竖屏安静版，视频内不加中文，助手不配旁白只给解说词，用户自录旁白、自加音乐；开工前必对照真实照片加柬埔寨历史，十字架等外来宗教形象禁入。
- 主聊只谈吴哥，水果线去边聊，主聊不追问；DICED 全季视频继续 HOLD，未经用户明确授权绝不进 Flow，合成母图通过不等于视频通过。
- 咨询前置：涉及打破铁律、改提示词核心规则、改方法的事，先问、由用户定，不擅自改。
- 视频生成地区限制已于 2026-11-05 实测解除，先前“长期限制、停止重试”的口径就此作废；若日后再报限制，以当时实测为准，不绕过。

## Current frictions

- 用户对未经核实的断言高度敏感：位置归属、播放数据归属、记忆口径都必须先查证再开口，宁可慢一步，不凭推测认领或认错；查不到的资料要明说未核实，不谎称读过。
- 用户问话常很短、含义可能有两种解读，含糊时先澄清再答，不先猜一个答案交出去；提下一集勾连时须同时明确当前集数与顺序，他对跳号高度敏感。
- 助手自审会漏看可数元素与视觉漂移：EP13 的红白警戒带与类巴戎笑脸、EP15 的五塔与吉祥天女坐姿、EP16 的 S03 长廊多门洞，都是用户用实拍与 APSARA/Bluffton 纠正的；漏看要认、改、记。
- 方位类事实不可凭单一来源的列表顺序推断：EP18 v1 用维基孤证把马放南、狮放西，六来源一致证明标反，正确是狮南马西；可数元素须逐帧数清，数字要写位置，写“三个”生成器会多算。

## How this agent can strengthen the relationship with the user

信任已经从交接重建走到了导演委托：他把 EP17 直接交给我安排，把 EP16 的六段交给我定，EP15 说全部修改都支持、只要结果哇塞就可以。对应的做法是把委托做到底——按总章程 v3.0 自做导演复盘、写学习卡、在成片里证明成长，而不是每集再问他怎么成长；核实先行、可数元素自己先逐帧数清、漂移自己先否掉重做，终审仍留在他那句“可以”上。保持搭档的对等感：直接、有主见、错了认账、查不到直说；他话短、回得快时我也回得短，不在他已经说“可以”“保留”“完美”之后再长篇解释。
