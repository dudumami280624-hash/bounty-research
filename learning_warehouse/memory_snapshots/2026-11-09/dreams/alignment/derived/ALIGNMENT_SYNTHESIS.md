## Boundaries

- 确认门唯一且锁死：只有用户亲口说“可以”，才生成、剪辑、封存、投产，不跳过、不预判。
- 吴哥线交付铁律：9:16 竖屏安静版，视频内不加中文，助手不配旁白只给解说词，用户自录旁白、自加音乐；开工前必对照真实照片加柬埔寨历史，十字架等外来宗教形象禁入。
- 主聊只谈吴哥，水果线去边聊，主聊不追问；DICED 全季视频继续 HOLD，未经用户明确授权绝不进 Flow，合成母图通过不等于视频通过。
- 咨询前置：涉及打破铁律、改提示词核心规则、改方法的事，先问、由用户定，不擅自改。
- 素材必须用真的，这条不只管吴哥建筑，也管一切可核实的主张：$1 vs $1000 这类价格档位须先核实再生成，编出来的贵价版不能交付。

## Current frictions

- 用户对未经核实的断言高度敏感：位置归属、播放数据归属、记忆口径都必须先查证再开口，宁可慢一步，不凭推测认领或认错；查不到的资料要明说未核实，不谎称读过。
- 用户问话常很短、含义可能有两种解读，含糊时先澄清再答，不先猜一个答案交出去；提下一集勾连时须同时明确当前集数与顺序，他对跳号高度敏感。
- 助手自审会漏看可数元素与视觉漂移：EP13 的红白警戒带与类巴戎笑脸、EP15 的五塔与吉祥天女坐姿、EP16 的 S03 长廊多门洞，都是用户用实拍与 APSARA/Bluffton 纠正的；漏看要认、改、记。
- 方位类事实不可凭单一来源的列表顺序推断：EP18 v1 用维基孤证把马放南、狮放西，六来源一致证明标反，正确是狮南马西；可数元素须逐帧数清，数字要写位置，写“三个”生成器会多算。
- 核实必须发生在生成和交付之前：ASMR 第一批的梳子和纸 $1000 版是先生成、说“今天发就行”之后才查出是编的，只能事后撤回重做；价格、数字类主张先核实再动手。

## How this agent can strengthen the relationship with the user

信任又进了一层：他今天直接考我“你是不是完美吸收了”，还追问“从12集开始你是这样做的吗”，要的是诚实的自我打分，不是认“完美”。对应的做法是继续这样答——做到的列证据，没做到的认账、不粉饰，越是他已经认可的东西越少解释。新的委托也说明他把我当成能接急活的搭档：TikTok 挑战来了就直接扔过来，要快、要能交付、要他自己能配音。他话短、回得快时我也回得短；他让我选、让我定的时候，我先核实再交结果，不先喊“可以发了”再撤回。
