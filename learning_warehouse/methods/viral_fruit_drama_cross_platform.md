# 跨平台爆火水果剧 · 已转化的方法（2026-11-02 调研转化）

来源：2026-11-02 跨平台调研（TikTok、YouTube Shorts、Facebook Reels、Instagram Reels、抖音、ReelShort/DramaBox，附红果对照），只转化规律与机制，不抄任何人的剧情、角色、台词、画面。
适用：原创 90 秒水果短剧，不直接套用于吴哥纯欣赏系列。

## 通用引擎（各平台都成立）
- 一眼能认的人设：一个水果 = 一个颜色、一个形状、一个性格，零解说就能分清谁是谁。
- 熟悉的狗血引擎： rivalry、秘密、反转、选择，认真演，荒诞感自然出来。
- 节奏：1.5-2 秒一切，约每 10 秒一个转折， payoff 处可停 3-4 秒。
- 结尾：关一个小 loop，开一个更大的 loop，留一个具体问题让人评论、转发、追更。
- 系列化：固定班底、固定场景、固定开场信号、编号 Ep. N，中途进来的观众 5 秒内能定向。
- 原创是变现门：各平台都罚近似复制、模板换皮、水印重发，换皮不是捷径。

## 90 秒模板（从调研推导的原创结构）
- 0-3 秒：冲突中开场，脸贴镜头，8 字以内文字，不要问候、不要 logo。
- 3-15 秒：立人设、立挑战。
- 15-30 秒：否认、升级。
- 30-45 秒：第三个人进场。
- 45-60 秒：给一个小 payoff，但惹出更大的麻烦。
- 60-75 秒：一次反转。
- 75-87 秒：沉默反应停顿。
- 87-90 秒：悬念卡 + 一个具体评论问题。
- 每集最多 3 个常驻人物，全用自己的音乐和声音，结尾帧与开头帧能循环接上。

## 各平台借一样 / 不借一样
- TikTok：借节奏 + 悬念；不借模板农场。90 秒过 1 分钟收益门槛。
- YouTube Shorts：借播单 + 季节连播 + 可搜索标题；不把时长硬撑到 3 分钟，不用有版权主张的音乐做 90 秒（超 1 分钟有主张会被全球屏蔽）。
- Facebook Reels：借 90 秒正好 fits + 可分享的问题 + 静音字幕；不用带水印的跨平台重发。
- Instagram Reels：借 Trial Reels 测 90 秒 vs 60 秒 + 为 DM 转发送设计；不靠精致无转折。
- 抖音：借一冲突一集 + 专属声音 motif；不模板换皮、不无标签、不套用付费墙和长剧集慢 withholding。抖音是独立系统，需中文版、可见标签、预审、本地合规，不能直接重发。
- ReelShort / DramaBox：借一集一震惊 + 系列圣经；不慢 withholding、不付费墙钩子、不预告大于正片。信息流观众没有沉没成本，会直接划走。

## 红线（每次定剧本、发片前必过）
- 不抄角色、名字、剧情、台词、画面、 beat 顺序，只借引擎。
- 不用人格羞辱类笑点做主引擎，改走选择与 rivalry。
- AI 标注按平台来：卡通水果一般可豁免，但写实人声、写实画面要开标签，抖音一律要可见标签 + 元数据。
- 数字只用第三方快照的量级参考，不当保证；平台规则以发片时官方口径为准，调研里的门槛、价格、日期均为 2026-11-02 的索引读数，非实测。
- 创作与审核分离：本方法只定规律，新剧本逻辑稿审过后才逐镜制作，封存只在用户说“可以”之后。

## 全球补查补充（2026-11-02，实事求是口径）
- 没有可靠总账：找不到跨平台水果剧总数、总播放的可信统计，能证据化的是波次：2 月底先兆、3 月英文旗舰、3-5 月西班牙语浪潮、法语土耳其语中文印度语平行改编、9-10 月西班牙语第二波。凡无方法的“几十亿、几百频道”一律不当事实。
- 旗舰数要分开记：媒体转述约 3.3m 粉丝 / 约 300m 播放，与创作者自站 92m+ 总播放、19 集冲突，集数另有 22、25-28 集说法，绝不平均、绝不合并；12 集被删、收益资格被撤是创作者说法，平台未证实原因。
- 格式走通靠翻译当地电视语法，不是翻译同一剧：英文约会别墅、西班牙语家庭伦理剧、法语诱惑真人秀、土耳其婆媳剧、中文总裁复仇离婚剧。能借的是可视冲突与悬念机制，不能借的是现成 IP 格式、商业歌曲、真人脸和声音。
- 无证据≠有：小红书上未找到水果剧浪潮证据，ReelShort / DramaBox 上未找到水果剧系列证据，不能据此规划发行；中国微剧大数（43 万部、超 90% AI 等）是整个微剧市场，不是水果剧数，绝不混用。
- 长远教训：羞辱、性别化背叛、怀孕当羞耻、食人 / 监狱羞辱、儿童涉成人剧情，正是后来被删号、被停收益、被批评的点，新剧必须设计成让批评者、审核者、品牌方都无法这样描述它。
- 平台门槛均为二手转述（未直接读平台政策页），发片前必须在应用内再核对；收入无公开单价，绝不承诺按播放算钱。
