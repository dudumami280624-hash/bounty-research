# Flow / Veo 技术 · 已转化的方法

来源：公开 IG/FB 教程、Google Flow 官方账号公开简介、公开搜索整理，已去掉“评论索取提示词”、绕付费插件、换脸、危险特技等内容。

## 可直接用的方法
1. 两张图定一镜（Frames to Video）
   - 上传开头图＋结尾图，AI 补中间运动。
   - 用途：吴哥怕漂移的镜头、水果固定班底的转场。
   - 要点：两张图的角色、服装、场景、光色先统一，再生成。

2. 原料生成一镜（Ingredients to Video）
   - 把人物、道具、场景图一起当原料，生成一镜。
   - 用途：水果固定班底、固定场景的连载。

3. 画线定运镜
   - 在参考图上画一条路径线，AI 按线做无人机式运动。
   - 用途：吴哥引道往前走、登阶往上走、绕塔。
   - 要点：线要简单、方向明确，不要画复杂折线。

4. 短命令控镜头
   - 用短命令代替长段描述，例如无人机飞、变焦、微距、焦点转移、运动模糊。
   - 用途：每镜只控一个运动，失败率低。

5. 结构参考
   - 9:16 竖屏、每镜约 8 秒、5 镜一集、每镜一个动作。
   - 角色一致性靠同一张参考图反复用，不靠每次重写描述。

## 不能学的东西
- 第三方插件绕过 Flow 付费、无限用 Veo：公开评论里已有用户说没用、不可信。
- 换脸进别人视频、卡车压人等危险假特技：不学、不做。
- “评论 XX 就私信发提示词”：那是引流套路，不是方法本身。
